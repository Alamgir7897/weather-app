 ## 🌦️ Weather App

A simple and responsive Weather Application that shows real-time weather information like temperature,
humidity, and weather conditions for any city using a Weather API.

---

## 🚀 Features
🔍 Search weather by city name

🌡️ Displays temperature in real time

💧 Shows humidity and weather condition

🎨 Clean & responsive UI (Glassmorphism style)

⚡ Uses live Weather API

---

## 🛠️ Technologies Used
HTML

CSS

JavaScript

Weather API
